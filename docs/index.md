# builder

**builder** is a static site generator, like [Hugo](https://gohugo.io/): it
turns Markdown files into plain HTML pages you can host anywhere, meant for
building websites that host puzzles on any theme.

It's built primarily to power the official
[tricky bits](https://trickybits.dev) website
([source](https://github.com/tricky-bits/website)), a puzzle hunt site. But
it's a general-purpose tool, anyone can use it to build their own site.
