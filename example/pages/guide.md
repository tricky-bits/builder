# Author's Guide

This page exists for two reasons: it explains how the example is structured, and
it proves that **a standalone page can be added to the navbar** by listing it
under `[[site.nav_items]]` in `tbb.toml`.

Everything you see on this site is generated by **TBB** (Tricky Bits Builder)
from plain markdown files with YAML frontmatter. No database, no server — the
output is a folder of static HTML with client-side answer checking.

## Project layout

A TBB project points at an input directory and writes a self-contained site to
an output directory:

```
example/
├── tbb.toml          # build + site configuration
├── pages/            # standalone pages → /<slug>.html
│   ├── about.md
│   ├── guide.md
│   └── terms.md
└── campaigns/        # each subdirectory is one campaign
    └── <campaign>/
        ├── campaign.md
        └── stages/
            └── *.md  # one file per stage
```

## Campaigns and stages

- A **campaign** groups related stages under a theme. Its `campaign.md`
  frontmatter sets `title`, `category`, `difficulty`, `order`, and whether it is
  `featured`.
- Each **stage** is one markdown file. Stages form a **linear chain**: exactly one
  stage is marked `start: true`, and each stage points to the `next` one by slug.

| Concept    | Lives in            | Key frontmatter                          |
| ---------- | ------------------- | ---------------------------------------- |
| Site       | `tbb.toml`          | `nav_items`, `index_title`, `theme`      |
| Page       | `pages/*.md`        | `title`, `slug`                          |
| Campaign   | `campaign.md`       | `category`, `order`, `featured`          |
| Stage      | `stages/*.md`       | `start`, `next`, `answer`, `hints`       |

## Answers

Answers are checked **in the browser** using SHA-256 — the plaintext answer never
ships in the page. On a real puzzle you would hide the solution. In *this* example
the goal is to show the system, not to stump you, so **every stage states its
answer in bold** in the body text. Type it (lowercase, trimmed) to advance.

## Build it yourself

From the repository root:

```sh
go run . build -c example/tbb.toml
# output lands in example/public/
```

Then open `example/public/index.html` in a browser.
