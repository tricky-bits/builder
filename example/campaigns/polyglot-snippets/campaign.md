**Polyglot Snippets** exists to show off **fenced code blocks**.

Each stage presents a snippet in a different language using triple-backtick
fences with a language tag (`go`, `python`, `sql`). The answer is always
the name of the language, and — as everywhere on this example site — it's
written in **bold** in the stage text.

This campaign also demonstrates a **real featured image**: there's a
`featured.png` next to this file, so the home page uses it instead of an
automatic theme fallback.
